Perfect Dark

Perfect Dark PC port · Port

Port baseado na decompilação, com campanha e multiplayer local documentados.

Arquivos originais

ROM própria; USA Rev 1 / NTSC-final recomendada.

Requisitos

  • Windows 7+, Linux ou macOS; confira arquitetura e requisitos gráficos no guia.

Como começar a instalação

  1. Obtenha a build indicada no README para seu sistema.
  2. Crie data junto do executável, coloque pd.ntsc-final.z64 e inicie.

Limitações conhecidas

Bugs gráficos, de gameplay e crashes ocasionais; outras regiões podem exigir build própria.

Bora de Play

Não distribuímos jogos, BIOS, chaves ou arquivos protegidos.
